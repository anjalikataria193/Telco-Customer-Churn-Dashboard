# Telco Customer Churn Analysis

## Project Overview

This project analyzes customer churn for a telecommunications company. The goal is to explore customer data, identify patterns and factors associated with churn, and present the findings through an interactive Power BI dashboard.

## Objectives

- Analyze customer churn patterns.
- Identify customer characteristics associated with churn.
- Explore important factors that may influence customer retention.
- Perform Exploratory Data Analysis (EDA) using Python.
- Create an interactive Power BI dashboard to communicate key insights.

## Tools & Technologies

- **Python**
- **Jupyter Notebook**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Power BI**
- **GitHub**

## Project Files

### `Telco Customer Churn.ipynb`
Contains the Python-based Exploratory Data Analysis (EDA), including data exploration, cleaning, visualization, and analysis.

### `Telco Customer Churn Dashboard.pbix`
Contains the interactive Power BI dashboard created to visualize customer churn patterns and key insights.

## Analysis Performed

The project includes analysis of areas such as:

- Customer churn distribution
- Customer demographics
- Contract and tenure patterns
- Payment methods
- Services used by customers
- Monthly and total charges
- Churn across different customer segments

## Dashboard

The Power BI dashboard provides an interactive view of customer churn and allows users to explore important patterns and customer segments.

## Conclusion

The analysis helps understand customer churn behavior and highlights factors that can be useful for improving customer retention strategies. The combination of Python-based EDA and Power BI visualization provides both detailed analysis and an easy-to-understand business view.
